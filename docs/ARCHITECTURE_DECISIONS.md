## Темы, требующие исследования до решения
- Mass Entity в 5.8: стабильность API, стоимость на 10k–100k сущностей.
- Формат/рантайм локальной модели для AETHER.
- Сфера: схема сетки (икосаэдр/cubed-sphere) и стыковка с локальными тайлами.
- Генерация языков: уровень детализации грамматики для v1.
