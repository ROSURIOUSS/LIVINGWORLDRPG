# VISION

**LIVINGWORLDRPG — не игра с живым миром, а живой мир, в котором можно играть.**

Симуляция фэнтезийной планеты: государства, культуры, религии, языки, экономика, экология и разумные существа развиваются независимо от игрока. Нет обязательного сюжета и «избранного». Игрок рождается случайным жителем в случайную эпоху, в семье, подобранной миром; после смерти продолжает за наследника, мир не останавливается.

## Столпы
1. **Мир первичен.** Симуляция не ориентируется на игрока; истории возникают из взаимодействия систем.
2. **Причинность.** Каждое историческое событие имеет причины, участников, последствия. Никаких независимых случайных чисел там, где нужна зависимость (климат → растительность → животные → ресурсы → торговля → политика → войны → миграции → культура).
3. **Воспроизводимость.** Seed + версия генератора + настройки = один и тот же мир.
4. **Знание ≠ истина.** Игрок и NPC знают только то, что до них дошло (слухи, письма, книги), возможно искажённое.
5. **AETHER помогает, не заменяет.** ИИ-подсистема предлагает; правила ядра решают. Игра полностью работает офлайн.
6. **Масштаб через уровни симуляции**, а не через «симулировать всё каждый кадр».

## Не-цели
Классовые системы, экран создания персонажа (кроме опционального режима), фиксированный сюжет, обязательная LLM, мультиплеер в v1.

## Оригинальность
Расы, мифология, названия — оригинальные; без копирования защищённых франшиз.
