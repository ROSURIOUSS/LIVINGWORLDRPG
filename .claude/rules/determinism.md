# Детерминизм симуляции
- Весь рандом — через `FLWRng` (PCG32/xoshiro), сидированный `(WorldSeed, SystemId, EntityId, Tick)`. Запрещены `FMath::Rand*`, `FRandomStream` без явного сида, системное время, `FPlatformTime` в логике.
- Порядок обработки сущностей — по возрастающему `FLWId`; не итерируй `TMap/TSet` там, где порядок влияет на результат.
- Float в ядре: фиксированный порядок операций; для критичных величин — fixed-point/int64.
- Версия генератора (`GeneratorVersion`) хранится в мире; изменение алгоритма = новая версия, старая остаётся рабочей.
- Каждая новая симуляционная система обязана иметь тест воспроизводимости: тот же Seed → бит-в-бит одинаковый хэш состояния.
