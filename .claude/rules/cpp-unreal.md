# C++ / Unreal
- Ядро симуляции — чистые C++ структуры/классы без UObject/AActor (`Core`, `Sim`); UObject/Actor только в слое представления.
- Зависимости модулей строго однонаправленные (см. TECHNICAL_ARCHITECTURE §3); проверяй `Build.cs` при каждом изменении.
- Данные — SoA/компактные структуры, ID вместо указателей. Нет `UPROPERTY` на сотни тысяч сущностей.
- Тяжёлое — вне game thread (UE::Tasks), результаты применяются на game thread через очередь команд.
- Имена: префиксы UE (`F`,`U`,`A`,`E`,`I`), проектный префикс `LW`. Публичные API — с комментарием об ownership и частоте вызова.
- После изменений: сборка (`/build`) и затронутые тесты (`/test`). Новый код без теста не получает статус выше PROTOTYPE.
